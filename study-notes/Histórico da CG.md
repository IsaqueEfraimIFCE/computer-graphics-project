# Histórico da Computação Gráfica

| Período | Marco |
|---|---|
| 1950 | MIT cria o **Whirlwind I**, primeiro computador com recursos gráficos. |
| 1955 | Sistema de monitoramento de voos exibe dados de radar no Whirlwind. |
| 1959 | Surge o termo **Computer Graphics**, num projeto de simulação de voo. |
| 1962 | Tese de Sutherland, **Sketchpad** — base das estruturas de dados da CG e dos primeiros sistemas **CAD**. |
| Anos 1970 | A CG vira área própria; surgem técnicas de sombreamento e profundidade (**z-buffer**); em 1975 aparece o primeiro computador com interface visual. |
| Anos 1980 | Tentativas de padronização (**CORE, GKS, PHIGS**); **ray tracing** e **radiosidade** levam o realismo à qualidade fotográfica. |
| Anos 1990 | Surge o **OpenGL**; placas gráficas para PC e GPUs popularizam a CG. |
| Anos 2000 | As câmeras se popularizam. |
| Anos 2010 | Era da IoT e dos dispositivos móveis: algoritmos fundamentais de CG rodando em hardware embarcado com pouco recurso gráfico. |
